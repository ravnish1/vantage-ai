# Vantage AI

**Vantage** is a premium AI-driven talent assessment platform that goes beyond resumes to test what candidates actually know — and tells them exactly how to close the gaps.

## 🧠 The Mission
A resume tells you what someone **claims** to know — not how well they actually know it. Vantage fixes that by providing an adaptive, skill-by-skill conversational assessment that identifies real-world proficiency.

## 🛠️ Tech Stack
- **Frontend**: Next.js 14+ (App Router)
- **Styling**: Vanilla CSS (Premium Glassmorphism)
- **AI Engine**: OpenAI GPT-4o
- **Visuals**: Chart.js Radar Charts

## 🚀 Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Setup environment variables**:
   Create a `.env.local` file:
   ```env
   OPENAI_API_KEY=your_key_here
   ```

3. **Run the app**:
   ```bash
   npm run dev
   ```
